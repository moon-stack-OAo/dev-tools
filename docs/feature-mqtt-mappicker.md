# MQTT 调试 · 地图选址 — 功能清单

> 状态：**MQTT 已按 MQTTX 工作台对齐**（三区布局 + 过滤/气泡/JSON + 预设/LWT/统计/导出）；地图选址仍为 P0  
> 分类：`debug`  
> 约束：纯前端、浏览器本地处理；与现有 WS / STOMP / SSE / HTTP 调试工具风格对齐  
> 更新日期：2026-08-13

---

## 总原则

| 项       | 建议                                                                                                        |
|---------|-----------------------------------------------------------------------------------------------------------|
| 分类      | 均放 `debug`                                                                                                |
| 依赖      | MQTT → `mqtt.js`（浏览器包）；地图 → **Leaflet + OSM 瓦片**（轻、文档多）                                                   |
| 数据      | 连接 / 消息 / 坐标默认只在浏览器；可选 `localStorage` 记历史                                                                 |
| 布局      | 双栏：左配置 / 右日志或结果（对齐 `httpdebug` / `sse`）                                                                   |
| MQTT 限制 | 浏览器侧多为 **WebSocket**（`ws://` / `wss://`）；纯 TCP 1883 需后端桥（**本期不做**）                                        |
| 地图限制    | 瓦片来自公网（OSM 等），**离线包不内置**；可配置自定义 tile URL                                                                  |
| 路径约定    | 脚本 `js/debug/{id}.js`，面板 `html/panels/debug/{id}.html`，样式 `css/debug.css`（前缀短名），注册 `js/tools-registry.js` |

# 一、MQTT 调试

### 元信息（建议）

| 字段     | 值                                                                 |
|--------|-------------------------------------------------------------------|
| `id`   | `mqtt`                                                            |
| `name` | MQTT 调试                                                           |
| `cat`  | `debug`                                                           |
| `icon` | `bi-broadcast-pin`（或 `bi-hdd-network`）                            |
| `desc` | MQTT over WebSocket 连接 / 订阅 / 发布 / 消息日志                           |
| `tags` | `["common","backend"]`                                            |
| 第三方库   | `mqtt` browser build → `public/lib/mqtt.min.js` + `toolLibs.mqtt` |

### 定位

浏览器内 **MQTT over WebSocket** 连接、订阅/发布、主题过滤、消息日志。与现有 **WS / STOMP** 并列，面向物联网 / 消息中间件联调。

### 功能清单

#### P0 — 最小可用（建议首版）

| #  | 功能   | 说明                                                                       |
|----|------|--------------------------------------------------------------------------|
| M1 | 连接配置 | Broker URL（`ws(s)://host:port/path`）、ClientId（可随机生成）、Username / Password |
| M2 | 连接控制 | 连接 / 断开；状态灯（未连接 / 连接中 / 已连接 / 错误）                                        |
| M3 | 协议选项 | MQTT 3.1.1 / 5.0（若库支持）；Clean Session；Keep Alive；Connect Timeout          |
| M4 | 订阅   | 主题 + QoS(0/1/2)；多订阅列表；取消订阅；通配符 `+` / `#` 提示                              |
| M5 | 发布   | 主题、Payload（文本）、QoS、Retain 开关；一键发布                                        |
| M6 | 消息日志 | 收/发分色；时间、方向、topic、qos、retain、payload 预览；清空 / 复制                          |
| M7 | 错误提示 | 连接失败、鉴权失败、非法 topic 的 toast + 日志                                          |

#### P1 — 实用增强

| #   | 功能         | 说明                                                 |
|-----|------------|----------------------------------------------------|
| M8  | Payload 模式 | 文本 / JSON 格式化展示；超长截断 + 展开                          |
| M9  | 主题过滤       | 日志按 topic 关键字过滤                                    |
| M10 | 连接预设       | 保存 3～5 组本地预设（`localStorage`）                       |
| M11 | LWT        | Will Topic / Will Payload / Will QoS / Will Retain |
| M12 | 统计         | 连接时长、收/发条数、字节量（粗略）                                 |
| M13 | 示例         | 一键填入示例配置文案（避免写死不可用的公共 broker 地址）                   |

#### P2 — 进阶（可后置）

| #   | 功能          | 说明                                            |
|-----|-------------|-----------------------------------------------|
| M14 | MQTT 5 详情   | User Properties、Reason Code、Session Expiry 展示 |
| M15 | 二进制 Payload | Hex 查看 / 简单二进制说明                              |
| M16 | 批量订阅        | 多行 topic 一次订阅                                 |
| M17 | 导出日志        | 下载 JSON / CSV                                 |

### 明确不做（首版）

- 原生 TCP 1883（无 WebSocket 升级）
- 服务端桥接 / 云厂商专用 SDK
- 证书双向 TLS 文件上传（可用 `wss` + 系统信任；自定义 CA 难做）
- 依赖 `/__cors_proxy`（**WebSocket 不能走该 HTTP 代理**）

### UI 草图

```
[ URL ] [ClientId] [用户] [密码]  [连接][断开]  ● 状态
[ 协议 v3.1.1|v5 ] [Clean] [KeepAlive] [LWT 折叠]

左：订阅列表 + 新增订阅 | 发布区（topic / qos / retain / payload）
右：消息日志（过滤 / 清空 / 复制）
底：说明（须 ws/wss；跨域 / 混合内容注意）
```

### 类名与文件建议

| 资源 | 路径 / 约定                                                    |
|----|------------------------------------------------------------|
| 面板 | `html/panels/debug/mqtt.html`，根节点 `#panel-mqtt`            |
| 脚本 | `js/debug/mqtt.js`，函数前缀 `mqtt`                             |
| 样式 | `css/debug.css` 内 `.mqtt-*`                                |
| 单测 | `test/debug/mqtt.test.js`（纯函数：ClientId 生成、topic 校验、日志格式化等） |

# 二、地图选址

### 元信息（建议）

| 字段     | 值                                                       |
|--------|---------------------------------------------------------|
| `id`   | `mappicker`                                             |
| `name` | 地图选址                                                    |
| `cat`  | `debug`（若更偏「生成坐标给业务」可改为 `generate`）                     |
| `icon` | `bi-geo-alt`                                            |
| `desc` | 瓦片地图点选坐标 / 复制经纬度 / 可选地名搜索                               |
| `tags` | `["common","frontend","backend"]`                       |
| 第三方库   | Leaflet（JS + CSS）→ `public/lib/` + `toolLibs.mappicker` |

### 定位

瓦片底图上点选 / 搜索位置，输出 **经纬度、地址（可选）、多种坐标串**，供开发对接（表单、API、LBS）。

### 功能清单

#### P0 — 最小可用（建议首版）

| #  | 功能   | 说明                                                                    |
|----|------|-----------------------------------------------------------------------|
| G1 | 瓦片底图 | 默认 OSM；可配置 Tile URL 模板（`{z}/{x}/{y}`）                                 |
| G2 | 地图交互 | 缩放、拖拽、双击缩放；比例尺（可选）                                                    |
| G3 | 点选   | 单击落点 / 拖拽 Marker；显示当前 lat/lng（小数位可配，默认 6～8 位）                         |
| G4 | 坐标输入 | 输入 `lat,lng` 或 `lng,lat` → 定位并落点                                      |
| G5 | 输出区  | 复制：`lat,lng` / `lng,lat` / JSON `{lat,lng}`；可附高德/腾讯风格字段说明（仅格式，不绑 Key） |
| G6 | 状态   | 当前缩放级别 `z`、地图中心点                                                      |

#### P1 — 实用增强

| #   | 功能            | 说明                                        |
|-----|---------------|-------------------------------------------|
| G7  | 搜索（Nominatim） | 地名 → 候选列表 → 跳转（**依赖公网**；注意限流与使用政策；失败友好提示） |
| G8  | 逆地理           | 点选后查地址文案（同上 Nominatim，可开关）                |
| G9  | 多标记           | 最多 N 个点列表；选中 / 删除；导出点集 JSON               |
| G10 | 预设视图          | 中国全图 / 上次位置（`localStorage`）               |
| G11 | 坐标系提示         | **WGS84** 说明；首版不做 GCJ-02 内置纠偏（可文案 + 外链）   |
| G12 | 绘制辅助          | 十字准星 / 点击地图任意处更新（与 Marker 同步）             |

#### P2 — 进阶（可后置）

| #   | 功能       | 说明                                                  |
|-----|----------|-----------------------------------------------------|
| G13 | 矩形 / 多边形 | 框选范围，输出 bbox / GeoJSON                              |
| G14 | 测距       | 折线距离（米 / 公里）                                        |
| G15 | 多底图      | OSM / 其他可公开 tile / 自定义切换                            |
| G16 | 导入       | 粘贴 GeoJSON Point / 简单 CSV                           |
| G17 | 商业 SDK   | 高德 / 谷歌等需 API Key，**默认不做**；文档可说明「自定义 tile + 自备 Key」 |

### 明确不做（首版）

- 官方商业地图 SDK（Key、配额、合规成本高）
- 精确国内加密坐标互转（无权威库时易错，可 P2 再议）
- 离线完整中国瓦片包（体积巨大）

### UI 草图

```
顶栏：[搜索框] [定位到坐标] [清空标记] [底图/瓦片设置]
主区：Leaflet 地图 + Marker
侧栏：当前点 lat/lng、地址、复制按钮组、点列表
底栏：说明（WGS84 / 瓦片来源 / OSM 使用政策）
```

### 类名与文件建议

| 资源 | 路径 / 约定                                                   |
|----|-----------------------------------------------------------|
| 面板 | `html/panels/debug/mappicker.html`，根节点 `#panel-mappicker` |
| 脚本 | `js/debug/mappicker.js`，函数前缀 `mp` 或 `mappicker`           |
| 样式 | `css/debug.css` 内 `.mp-*`（地图容器高度、侧栏）                      |
| 单测 | `test/debug/mappicker.test.js`（坐标解析、格式化输出、bbox 等纯函数）      |

### 瓦片与外网说明

| 项        | 说明                                                                                                                                                    |
|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| 默认瓦片     | `https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`（须遵守 [OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)；生产可换自建 / 国内镜像） |
| 搜索 / 逆地理 | 浏览器直连 Nominatim（CORS / 限流风险）→ 失败则仅保留「坐标点选」                                                                                                            |
| CSP      | 需允许 `img-src` 瓦片域名；若 tile 为 https，现有 `img-src 'self' data: blob:` **可能不足**，实现时评估是否扩展 CSP 或仅用同源代理瓦片（一般不代理瓦片流量）                                         |

# 三、落地优先级

| 顺序 | 范围                             | 预估复杂度         |
|----|--------------------------------|---------------|
| 1  | **MQTT P0**（连接 / 订阅 / 发布 / 日志） | 中（类 ws/stomp） |
| 2  | **地图选址 P0**（瓦片 + 点选 + 坐标复制）    | 中（Leaflet）    |
| 3  | MQTT P1（预设、LWT、JSON、过滤）        | 低～中           |
| 4  | 地图 P1（搜索 / 逆地理、多点）             | 中（外网依赖）       |
