使用说明
  • 支持 JSON ↔ CSV、JSON ↔ Excel、CSV ↔ Excel 六种互转（默认 JSON → CSV）
  • 原「JSON ↔ CSV」已并入本页，用上方来源/目标切换即可
  • 嵌套对象可展平为点路径（如 address.city）；CSV→JSON 可勾选反展平
  • Excel 多 Sheet 时，左侧下拉切换；SheetJS 首次使用按需加载
  • 支持拖拽上传 CSV / Excel / JSON
