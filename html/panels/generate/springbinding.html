配置键（支持 camel / kebab / snake / ENV / 点号）
结果（多种 relaxed 形式）
说明：
  • camelCase: myPropName
  • kebab-case: my-prop-name（application.yml 常用）
  • snake_case: my_prop_name
  • ENV: MY_PROP_NAME（. 与 - 均变为 _，并大写）
  • system property / canonical: 点分小写 my.prop.name
  • 简化实现，覆盖 Spring Boot relaxed binding 约 90% 常见场景
